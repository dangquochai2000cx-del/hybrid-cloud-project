### Week 7 Objectives:

- Learn the process of deploying a web server on Amazon EC2.
- Install and configure Nginx on an Ubuntu Server instance.
- Configure Security Groups to allow external access to the web service.
- Test website accessibility through the public IP address of the EC2 instance.
- Prepare the web server as a foundation for deploying monitoring tools in the following weeks.
