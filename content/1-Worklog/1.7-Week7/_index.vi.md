### Mục tiêu tuần 7:

- Tìm hiểu quy trình triển khai máy chủ web trên Amazon EC2.
- Cài đặt và cấu hình Nginx trên máy chủ Ubuntu Server.
- Cấu hình Security Group để cho phép truy cập dịch vụ web từ bên ngoài.
- Kiểm tra khả năng truy cập website thông qua địa chỉ IP public của EC2.
- Chuẩn bị máy chủ web làm nền tảng cho việc triển khai các công cụ giám sát trong những tuần tiếp theo.

### Kết quả đạt được trong tuần 7:

- Hiểu quy trình triển khai máy chủ web trên Amazon EC2.
- Tìm hiểu và thực hiện cài đặt Nginx trên Ubuntu Server.
- Kiểm tra trạng thái dịch vụ Nginx và cấu hình để dịch vụ có thể khởi động cùng hệ thống.
- Cấu hình Security Group để cho phép truy cập HTTP qua cổng TCP 80.
- Tìm hiểu cách kiểm tra và xử lý các vấn đề liên quan đến dịch vụ web, địa chỉ IP và quy tắc bảo mật.
- Kiểm tra khả năng truy cập website thông qua địa chỉ IP public của EC2.
- Chuẩn bị máy chủ web cho giai đoạn cài đặt Prometheus và Node Exporter để giám sát tài nguyên trong tuần 8.
