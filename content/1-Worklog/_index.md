**On this page**, you will need to introduce your worklog. **How** did you complete it? How many weeks did you take to complete the program? **What** did you do in those weeks?

Typically, and as a standard, a worklog is carried out over about 3 months (throughout the internship period) with weekly contents as follows:

**Week 1:** [Introduction to AWS Cloud and Core AWS Services](1.1-week1/)

**Week 2:** [Hybrid Cloud Architecture Design and IP Address Planning](1.2-week2/)

**Week 3:** [Deploying Amazon VPC, Subnets, Internet Gateway, and Route Tables](1.3-week3/)

**Week 4:** [Deploying Amazon EC2 and Configuring Security Groups](1.4-week4/)

**Week 5:** [Configuring AWS Site-to-Site VPN and Virtual Private Gateway](1.5-week5/)

**Week 6:** [Integrating the Enterprise Network with AWS and Testing VPN Routing](1.6-week6/)

**Week 7:** [Deploying a Web Server on Amazon EC2 Using Nginx](1.7-week7/)

**Week 8:** [Installing Prometheus and Node Exporter to Monitor EC2 Instances](1.8-week8/)

**Week 9:** [Integrating Grafana and Building Dashboards to Monitor AWS Infrastructure](1.9-week9/)

**Week 10:** [Testing the Hybrid Cloud Environment, Evaluating Security, and Optimizing AWS Costs](1.10-week10/)

**Week 11:** [Doing task M...](1.11-week11/)

**Week 12:** [Doing task N...](1.12-week12/)
